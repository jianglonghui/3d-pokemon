# Zone 02：中段石室（z = +2 → -4）

> **叙事目的**：节奏放慢，从对抗感切换到神秘感。这是一个"有人在此长期生活"的空间。
> 阿卡娜不站在走道上，她在侧室里，玩家需要走近才能触发遭遇。

## 道具与陈设

### 研究区（偏西侧，x = -3 → -2）
这是阿卡娜的"工作台"区域，代表她在此研究多年的痕迹

**蜡烛群（candle_triple.gltf）**
- `(-3.5, 0.0, 0.5)`：地面大烛台，3根蜡烛，高亮
- `(-3.0, 0.0, -0.5)`：另一组蜡烛，略矮（rotation.y 偏转15°，随意感）
- `(-2.5, 0.0, 0.2)`：第三组，紧凑排列
- 意图：蜡烛不整齐，暗示她长时间在这里工作，摆放是自然形成的

**石台（复用 Altar 节点偏移）**
- 位置：`(-3.5, 0, 0)`，比原祭坛更靠西
- 用途：阿卡娜"工作台"，上面理论上放着笔记（暂无道具模型）

**拓印区**
- 西墙（x=-7）附近 z=0 到 z=-2：3个`torch.gltf`按不规则高度挂在墙上（`y = 1.5 / 2.0 / 2.5`），照亮墙面
- 叙事暗示：她在拓印墙上的古老石刻

### 柱子
- **P5 / P6**（z=+2，x=±4）：`pillar.gltf`，普通柱，承接Zone01的装饰柱
- **P7 / P8**（z=-3，x=±4）：`pillar.gltf`，标记研究区结束

### 阿卡娜的初始状态
- 初始位置：`(-3.0, 0, -1.0)`，蹲在石台旁（实现上用 idle 动画即可）
- 触发遭遇后：走到 `(0, 0, -2)` 中央站定，面朝南
- 战败后：返回石台旁，拿起笔记本（idle 动画）

## 视线与走位设计

```
玩家从 z=+2 继续北行：

    P5           P6      ← 柱廊收口

    [昏暗走廊]           ← 中央暗，视线被西侧亮光吸引

    [蜡烛群亮光]  (东侧暗) ← 玩家会本能向西看

    [A在石台旁]          ← 触发距离约 2.5u

    P7           P8      ← 区段结束标志
```

**关键设计原则**：阿卡娜不挡路。
她在偏西的研究区，而非走廊中央。玩家如果只是直行可能会从她旁边经过——但蜡烛的亮光会吸引玩家靠近，自然触发遭遇。这比"路中间一个人拦着"更符合她的角色气质。

## 叙事细节

- 西墙上若能显示纹理变化，应有若干刻痕（暂无美术支持，可用笔记占位）
- 蜡烛摆放方向略微朝向西墙，暗示阿卡娜的工作方向是研究墙上的东西
- P7/P8 之间（z=-3 中央）地面可加一圈蜡烛残迹（用极低高度的 candle_triple，y=-0.8 让蜡烛只露出火焰部分），暗示这里曾有某种仪式
