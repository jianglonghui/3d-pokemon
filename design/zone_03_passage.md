# Zone 03：深处通道（z = -4 → -11）

> **叙事目的**：压迫感最强的区段。光源极少，空间感收窄，Vex 从阴影里出现。
> 出口门洞是整个第一层的视觉焦点——玩家在击败Vex之后，第一次清晰地看见它。

## 道具与陈设

### 过渡柱（P9 / P10）
- 位置：`(±4, 0, -4)`，`pillar_decorated.gltf`
- 这是最后一对有花纹的柱子——过了这里，柱子消失，空间"失去秩序感"
- 意图：柱子从装饰 → 普通 → 消失，视觉上暗示越来越深入未知领域

### Vex 的站位
- 初始位置：`(0, 0, -6)`，背靠北方，面向南
- 她**不**站在开阔处，而是站在东西柱廊消失后的第一个无遮挡区域
- 这让她显得突然——玩家走过最后一对柱子，就直接面对她
- 她的两头缚灵（冕灵、壮者）初始状态：分别在她左右 `(±1.5, 0, -6)`，idle动画

### 祭坛区（z = -8）
- 已有资产：`altar` 节点位于 `(0, 0.5, -8)`
- **左蜡烛**：`candle_triple.gltf` @ `(-2.5, 1.0, -8)`（altar 台面高度）
- **右蜡烛**：`candle_triple.gltf` @ `(2.5, 1.0, -8)`
- 叙事意义：这座祭坛是旧帝国留下的，Vex 在它面前站岗，暗示她知道祭坛的意义
- 蜡烛燃烧中，说明Vex（或某人）最近刚点燃过它

### 北墙区（z = -10 → -11）
- 门洞两侧各一个`torch.gltf`，位于 `(±2.5, 2.2, -10.8)`（矮于其他火把）
  - 意图：门洞附近刻意减少照明——出口在黑暗中，强调未知与危险
- **Beacon 蓝光**（已有）：`(0, 1.5, -10.5)`，蓝色，是唯一指向出口的异色光
  - 叙事层面：这束蓝光来源不明。它不是火把，不是蜡烛。玩家第一次看见时应该感到好奇。
  - 可能来源（待后续揭示）：铁皮兽背上的印记与这束光有共鸣

**灯光意图**：
- 整段亮度从 Zone02 的暖黄，经过 Zone03 入口时骤然变暗（无补光）
- Vex 所在的 z=-6 区域是全层最暗的位置——她从阴影里出现
- 祭坛蜡烛恢复少量暖色，制造短暂的"呼吸感"，然后再次黑暗
- 蓝光是玩家在击败Vex走向出口时看到的第一束"不一样的光"

## 视线与走位设计

```
玩家从 z=-4 向北走：

  P9  [最后的装饰柱]  P10     ← 穿过这里，"秩序"消失

  [黑暗走廊，无遮挡]          ← 几乎看不清前方

  ·       [V 突然出现]  ·     ← Vex 在黑暗中，触发距离约 2.5u

  [战斗区，Vex退场]           ← 战败后 Vex 消失入东侧阴影

  [祭坛，蜡烛暖光]            ← 情绪节拍：短暂的静止与暖意

  ·     [蓝光，门洞]    ·     ← 玩家第一次清晰看见出口

  ═══════[下一层]═══════      ← 石门被印记打开
```

**关键设计原则**：Vex出现得"太突然"。
Zone01是框住的舞台感，Zone02是被蜡烛吸引的好奇感，Zone03是无预警的遭遇——黑暗走廊里没有任何视觉预告，Vex就站在那里。这与她的角色属性（刺客）完全一致。

## 叙事细节

- Vex 战败消失后，**祭坛上的蜡烛应该全部熄灭**（通过代码控制 PointLight visible = false）
  - 她离开，她燃的蜡烛也灭了
- 铁皮兽走向门洞时，背上的印记发光（与 beacon 同色 #66CCFF）
  - 可通过 `OmniLight3D` 动态挂载在铁皮兽节点上实现，强度极低（0.4），范围小（1.5u）
- 石门打开的瞬间，beacon 光应**增强再熄灭**（tween: energy 2→6→0）
  - 门开之后，蓝光消失，只剩黑暗的楼梯口
