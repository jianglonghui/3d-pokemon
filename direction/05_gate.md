# 石门序列 — 分镜设计

> 第一幕的句号。不用台词，只用镜头。

---

## 这一段没有对话

所有需要说的话都说完了。
加雷斯让玩家去，阿卡娜给了线索，Vex说了最后的警告。
门前不需要任何人再开口。

镜头只做一件事：**见证**。

---

## 序列分镜

### 镜头1：铁皮兽先走

```
【注视镜头 — 玩家全身，固定】
机位：玩家前方约4m，面对玩家（这是全游戏极少数从正面看玩家的镜头，但仍然背光）
画面：玩家轮廓，门洞在他身后
铁皮兽从他身边走出，走在他前面

铁皮兽没有被命令，它自己往前走了。
镜头从玩家移到铁皮兽——跟随铁皮兽，不跟随玩家。

这是第一次，铁皮兽比玩家先到某个地方。
```

### 镜头2：门上的印记

```
【特写 — 石门中央的帝国徽记，由远及近推镜，3秒】
画面：徽记轮廓，石纹，残破的刻痕

【硬切 — 铁皮兽背甲上的印记，同样角度同样距离】
第二次match cut（第一次在阿卡娜那里）
门上的图案和铁皮兽背上的图案——一模一样

镜头停2秒，不动。
观众连起来了。
```

### 镜头3：触碰

```
【极近特写 — 铁皮兽的甲壳手臂触碰门面的瞬间，低角度】
机位：几乎贴地，仰视
画面：铁皮兽的手，门，光从接触点开始扩散（蓝色）

这个镜头是整个序列里最小的画面——一只手，一扇门，一点光
但它是整个第一幕里最重的一刻
```

### 镜头4：门开

```
【拉远 — 广角，玩家和铁皮兽都在画面里，仰视石门】
机位：二者正前方，极低角度，仰视
石门向内打开，缓慢
门内是纯黑

画面：两个小小的轮廓，一扇巨大的门，门后是黑暗
镜头没有摇进去看——门内是什么，不知道

蓝光在门开的瞬间增强，然后熄灭
熄灭之后，只有火把的橙色照着门外
```

### 镜头5：玩家走进去

```
【注视镜头 — 固定在门外，看着玩家走进黑暗】
机位：门外，稍高，看着门洞
玩家走进去，他的轮廓越来越小，然后消失在黑暗里
铁皮兽跟着走进去

画面里只剩石门，和门后的黑暗

镜头停在门洞上——不跟进去。
```

### 镜头6：黑暗

```
【缓慢推向门洞 — 10秒】
镜头向门洞缓慢推近，速度极慢
画面逐渐被黑暗填满

不是切黑，是走进去的感觉
走进去，直到什么都看不见

黑。
```

## 音效设计提示（供参考）

| 时刻 | 声音 |
|------|------|
| 铁皮兽先走 | 只有脚步声，低沉 |
| 印记触碰门 | 低频共鸣，像远处的钟 |
| 门开 | 石头摩擦，极慢，厚重 |
| 蓝光熄灭 | 无声——熄灭是最响的声音 |
| 玩家走进黑暗 | 脚步声消失的那一帧是节奏点 |
| 推向黑暗 | 完全的寂静，或极远处的低鸣 |

## 给导演的注记

> 铁皮兽先走这件事，是整个序列最重要的一个动作。
>
> 它不是在引路，它是在回家。
> 三百年前有一个人，带着和现在这头铁皮兽印记相同的缚灵，走进了这座地窟，失踪在第七层。
> 现在铁皮兽先走进这扇门，是因为它认识这里。
>
> 玩家不知道这些，但他跟上去了。
> 这就够了。
