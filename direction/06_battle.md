# 战斗镜头设计

---

## 战斗镜头的职责

世界镜头服务于探索与情绪。
战斗镜头服务于**清晰度**和**节奏**。

战斗是玩家需要做决定的时刻，镜头不应当干扰判断，只应当加强每一个动作的重量。

---

## 标准机位

```
【主机位 — 战斗场景固定镜头】
位置：场地后方，偏高，斜45°俯视
左侧：我方角色（玩家缚灵）
右侧：对手缚灵

画面是对称的——两侧都清晰可见，没有一方被遮挡
FOV略宽（60°），确保双方完整入画
这是战斗的"默认状态"，所有非强调时刻都用这个机位
```

---

## 战斗开场：从世界过渡到战斗

```
【不切镜的过渡】
世界镜头开始：玩家和NPC之间触发战斗信号
世界镜头在这一帧快速向NPC推近（0.3秒，极快推镜）
然后 — 切到战斗场景主机位

意图：快速推镜模拟"冲突开始"的生理感受
不用黑屏过渡，不用转场特效，只是一次快推
```

---

## 技能释放

### 普通攻击

```
【主机位维持 — 不切镜】
攻击方冲向防御方
镜头在主机位上施加一次极轻微的震动（0.05u，0.15秒，恢复）
这是击中感的最小单位——不是抖动，是"落点"
```

### 强力技能

```
【快速切至侧面机位 — 0.5秒，然后返回主机位】
机位：战场侧方，与角色等高
画面：攻击方从侧面看，强调动作的弧度和速度

切换时机：技能动画的第一帧
返回时机：技能命中后0.2秒

这个侧面镜头只用于强力技能，不用于普通攻击
用少了，每次切镜都有意义
```

---

## 缚灵濒死

```
【特写 — 濒死缚灵面部或躯干，2秒】
机位：贴近，正面或3/4侧面
画面：它倒下或弯曲的瞬间

然后切广角 — 让玩家看见全局
这2秒的特写是给情感留出空间，不是为了戏剧效果
每一头缚灵都应该有这2秒，哪怕是对手的
```

---

## 战斗胜利

```
【主机位 — 不做特殊处理，1秒】
画面：对手缚灵倒下，我方站立
1秒静止，镜头不庆祝
然后切回世界场景（战后对话）

意图：胜利不需要镜头告诉你有多厉害
胜利是对手倒下，我方还站着，就这样
```

---

## 战斗失败

```
【特写 — 我方缚灵倒下，然后极缓慢拉远，5秒】
画面从特写缓慢拉到广角
玩家在画面里越来越小，对手越来越大

这5秒是唯一一次镜头"不站在玩家这边"的时刻
镜头在客观地记录：这一次，没有赢。
```

---

## 三场战斗的差异化

### 加雷斯的战斗
- 主机位比标准稍微偏正（更少俯角），让他看起来更高大
- 他的铁皮兽攻击时：侧面镜头角度偏低，强调力量而非速度

### 阿卡娜的战斗
- 她的幻灵攻击时：侧面镜头角度偏高，强调飘忽和不可预测
- 主机位略微偏向幻灵一侧——好像镜头也被她的奇异吸引

### Vex的战斗
- 主机位比标准更低，接近地面高度（压迫感）
- 她的冕灵和壮者轮流出场时，镜头在它们之间有一次慢摇——Vex在两头缚灵之间，镜头经过她，不停留
- 壮者的攻击：不用侧面镜头，强力攻击也用主机位——它的力量不需要特写，用全身更震撼
