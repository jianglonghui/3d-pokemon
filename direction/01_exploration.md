# 探索镜头

---

## 基本姿态：第三人称背后跟随

镜头始终位于玩家正后方偏高处，角度俯视约30°。
玩家轮廓占据画面下方中央，前方空间占画面2/3。

**这个构图的意义**：
- 前方永远比背后大——空间是待探索的，不是已知的
- 玩家的背影是唯一稳定的参照物——他走，我跟
- 玩家转向时镜头有0.3秒滞后——空间是真实的，不是贴图

---

## 入场镜头：玩家第一步踏入地窟

```
【建立镜头 — 3秒】
机位：地窟南端，高处，俯视向北
画面：整个地窟第一层全景，火把星星点点，北墙黑暗无光
玩家轮廓从画面最南端（最近处）入画，向北走去
镜头不动，只是看着他走进去

意图：告诉玩家——这个空间很深，而他只是其中一个很小的点。
```

```
【过渡 — 接常态跟随】
玩家走出建立镜头的范围后，切换为背后跟随视角
这一刻的切换要无缝——建立镜头的最后一帧和跟随镜头的第一帧，玩家位置、大小相同
```

## 探索中的自然变化

### 走进更暗的区域时

当玩家从Zone01进入Zone02（越过z=+2的柱子），镜头高度**缓慢降低0.5u**。

- Zone01：镜头偏高，开阔感，你能看见全局
- Zone02：镜头略低，蜡烛的细节进入视野，空间感变私密
- Zone03：镜头继续降低，玩家的肩膀占据更多画面，压迫感增加

没有切镜，是连续的缓慢变化。玩家不会察觉，但会感受到。

### 路过重要道具时

镜头轻微偏转——不是突然切，而是跟随方向微微向感兴趣的物体倾斜1-2°。

例如：玩家经过阿卡娜研究区的蜡烛群时，镜头会有一帧向西侧偏2°，然后回正。
这是本能的"眼神"，不是导演介入，是镜头在呼吸。

---

## 靠近出口时的仪式感

当玩家到达z=-8（祭坛区）之后，镜头开始缓慢升高——

```
z = -8  →  镜头高度开始上升
z = -10 →  已明显高于常态，可以看见门洞轮廓
z = -11 →  镜头达到最高点，玩家显得很小，门洞占据画面中央

意图：玩家物理上在走近，镜头在让他"变小"。
出口不是终点，是一个比他大得多的东西。
```
