## 核心原则速查

- **玩家从不露脸** — 背影是空白，每个人都可以是他
- **重要台词不切镜** — 尤其Vex，一句话一个机位
- **镜头落地时角色静止** — 运动的角色+运动的镜头=混乱
- **两个match cut** — 阿卡娜的笔记本→印记，石门徽记→印记
- **唯一对峙构图** — 只在Vex遭遇使用
- **镜头不庆祝胜利** — 胜利是对手倒下，1秒，切走
