# 加雷斯遭遇 — 分镜设计

> 情绪弧线：陌生的威慑 → 沉默的权威 → 意外的善意

---

## 遭遇前：玩家走向加雷斯

```
【跟随镜头 — 常态，4秒】
玩家从柱廊中走过，加雷斯的轮廓出现在画面中央远处
镜头不做任何特殊处理——这是刻意的
加雷斯只是站在那里，不需要镜头帮他制造威胁感
他本身就是威胁感
```

---

## 遭遇触发

```
【镜头轻推后 — 0.5秒】
触发遭遇信号的瞬间，镜头做一次极轻微的后退（玩家在画面中变小约5%）
这是生理本能的模拟：遇到危险时人会下意识退一步
不是突然切镜，是呼吸节奏里的一次暂停
```

---

## 加雷斯的台词

### "站住。"

```
【低角度仰视 — 加雷斯正面】
机位：玩家视角高度（约0.9m），微微仰视
画面：加雷斯全身，银甲，背后两侧各一把火把
火把逆光，他的正面在阴影里，只有甲胄边缘有光晕
他没有拔剑——空手挡路，比拔剑更有力量

构图意图：你在仰视他。不是因为他高，是因为他的姿态让你矮下去。
```

### "我拦住过数十个比你看起来更强的人。他们没有一个回来。"

```
【特写 — 加雷斯的眼睛，2秒】
机位：与他等高，正面，极近
画面：只有眼睛和鼻梁。没有嘴，没有下巴。
他不是在说"你会死"，他是在说"我见过太多死"。
他的眼睛是见过那些人的眼睛。

镜头不动。这两秒里什么也不发生。
这是本分镜里最重要的两秒。
```

### "离开。趁你还能走出去。"

```
【切回中景 — 加雷斯全身，从玩家后方看】
机位：玩家肩膀后方略高，看向加雷斯
现在画面里有两个人：玩家的背影（近，大）和加雷斯（远，小）
这是第一次在同一个画面里出现两个角色
构图意图：玩家和加雷斯之间有距离，但距离是可以跨越的——选择权在玩家手里
```

---

## 玩家选择

```
【选择界面期间 — 镜头呼吸】
镜头极其缓慢地向加雷斯方向推近（0.3u/秒），几乎察觉不到
这代表时间在流动，不是暂停
玩家做决定时，世界没有停下来等他
```

---

## 战斗结束：加雷斯倒下

```
【广角 — 战场全景，1秒】
机位：高处，俯视
画面：加雷斯单膝落地，刺背在旁边，玩家站在稍远处
广角是为了让你看见整件事的结果——不是特写的戏剧感，是真实发生了的事情

然后切近：
```

### "比我当年强。"

```
【压迫推镜 — 加雷斯面部，5秒】
机位：他面前约1.5m，与他跪地后的视线等高（约0.8m）
开始时：他的上半身在画面里
结束时：只有他的脸

这5秒里他说完了那两句话。
镜头一直在推，没有停。
"去吧。" — 说完这两个字，镜头停下来。
```

### "前方地板有裂缝……"

```
【切 — 加雷斯视角，看向玩家背影】
机位：加雷斯的位置，他的高度（他在跪着），仰视玩家
这是全片第一次用角色的主观视角
意图：这一刻我们站在加雷斯的位置上，看那个走进去的人。
他在说保护性的话，镜头位置也是仰望的——不是他软弱，是他在向那个人致敬。

玩家转身向北走，走出画面。
镜头留在原地，看着走廊。
3秒，切。
```

---

## 情绪节点总结

| 台词/动作 | 镜头 | 意图 |
|-----------|------|------|
| 触发遭遇 | 轻微后退 | 本能警觉 |
| "站住" | 仰视加雷斯 | 确立权威 |
| "没有一个回来" | 极近特写眼睛 | 传递见证过死亡的重量 |
| 选择对峙 | 双人中景（背面/正面） | 选择权在玩家 |
| 倒下 | 广角全景 | 客观呈现结果 |
| 独白 | 缓慢推镜至特写 | 让他的话有落点 |
| "去吧" | 他的主观视角仰望玩家 | 他在目送，不是在失败 |
