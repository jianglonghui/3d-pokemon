# 阿卡娜遭遇 — 分镜设计

> 情绪弧线：好奇被引导 → 智识上的打量 → 被看穿的沉默

---

## 入场：先看见房间，再看见人

```
【环境建立镜头 — 4秒，缓慢横摇】
机位：中高度，从东向西横扫研究区
画面依次经过：散落的蜡烛群 → 石台上的笔记（模糊） → 西墙上的拓印刻痕
没有人，只有痕迹

意图：这个空间在说话。
她在这里生活了很长时间，这比台词更有说服力。
玩家（和镜头）是在读一个人留下的物件，然后才遇见这个人。
```

```
【切 — 阿卡娜背面，中景】
她还没抬头，背对入口，坐在石台前
玩家的脚步声（音效）响起，她微微停顿
镜头在她背后，轻微向左移——偷偷看她的侧脸
```

---

## "你的脚步声不像士兵，也不像盗墓者。"

```
【维持 — 她的背影，说话时不切】
她说这句话时镜头不动，不切到玩家
这是意图的：她的背影在说话
一个不看你就能判断你是谁的人，比直视你更有力量
```

---

## 她转身，看见铁皮兽

```
【她转过来 — 中景正面，她的眼睛先落在玩家身上，然后落低】
她的目光向下移动——落到铁皮兽身上
镜头跟随她的视线，缓慢下摇：从她的脸 → 到铁皮兽

【特写 — 铁皮兽背甲上的印记，2秒】
画面：印记的纹路，火光下有光泽
这是第一次正式"看见"这个印记
镜头此刻不在乎玩家，不在乎阿卡娜——它只在看那个纹路
```

---

## "我在这里的记录里见过这种甲壳的纹路。"

```
【切回 — 阿卡娜面部特写】
她说这句话时表情不是兴奋，是一种"果然如此"的平静
她早就知道会有人带着这个印记来

【切 — 她走向铁皮兽，跟随镜头】
镜头跟着她移动，而不是跟着玩家
这是这场遭遇里镜头视角的关键选择：我们站在她的位置上，而不是玩家的位置上
她绕着铁皮兽走了半圈，蹲下来看印记，镜头跟到她的位置

【二人构图 — 阿卡娜蹲着/铁皮兽站着，玩家背影在后景失焦】
画面里玩家是模糊的，清晰的是阿卡娜和铁皮兽
意图：这一刻的对话发生在阿卡娜和铁皮兽之间，玩家是旁观者
```

---

## "……算了，不重要。"

```
【她站起，退后 — 镜头跟随后退】
她退后一步，镜头也轻微后退
画面重新包含玩家背影（重新对焦）、阿卡娜（中景）、铁皮兽（旁边）
三个角色第一次在一个构图里都清晰

这句"算了，不重要"——她没有说出那头缚灵的名字
镜头在她说完后停留1秒，什么都没切
那1秒是她没有说出口的名字
```

---

## 战斗结束：笔记本里的图

```
【广角 — 战后全景】
同加雷斯战败处理：客观，俯视，一秒

【切 — 阿卡娜手中的笔记本，俯拍特写】
画面：一幅粗糙的手绘图，纹路和铁皮兽印记相似
镜头慢慢拉近，图案充满画面

【硬切 — 铁皮兽背甲印记，特写】
同样的角度，同样的距离
两个镜头，同一个图案

这是全游戏第一个match cut。
不需要音效，不需要台词——观众自己连起来了。
```

---

## "你知道这个印记的意思，对吗。"

```
【中景 — 阿卡娜的背面，她在看玩家】
机位：玩家身后，越过玩家肩膀看阿卡娜
但她的脸不是对着镜头，她在看玩家（玩家在画面近景里，背对镜头）
她说这句话时是在看着玩家的背影说的

意图：她知道答案。这不是疑问，这是确认。
镜头不给她正面，因为她此刻不需要被看见——她在看。
玩家没有回答，没有转身。
镜头停留在这个构图里，沉默3秒。
然后，玩家向北走。
```

## 情绪节点总结

| 动作/台词 | 镜头 | 意图 |
|-----------|------|------|
| 进入石室 | 横扫环境，无人 | 物件先于人出场 |
| 她开口但不转身 | 她的背影 | 不看你就能判断你 |
| 目光落到铁皮兽 | 跟随视线下移，特写印记 | 第一次"看见"印记 |
| 绕着铁皮兽走 | 跟随她，玩家失焦 | 对话发生在她和铁皮兽之间 |
| "算了，不重要" | 停留1秒 | 那1秒是没说出口的名字 |
| 笔记本上的图 | Match cut至印记 | 无声的真相 |
| "你知道的，对吗" | 越过玩家肩膀看她 | 她在确认，不在问 |
