# Vex 遭遇 — 分镜设计

> 情绪弧线：被监视而不知 → 突然的对峙 → 说完就消失

---

## 关键设计决策

**Vex 的镜头处理与前两场完全不同。**

加雷斯：镜头给了他足够的仰视和特写，他值得被凝视。
阿卡娜：镜头跟着她的视线移动，她主导了观察。
Vex：镜头几乎不主动照顾她——她出现，她说话，她消失。镜头只是在场。

这是刻意的。Vex 不希望被看见，镜头尊重这一点。

---

## 入场：玩家不知道她已经在那里了

```
【注视镜头 — 固定高位，正对北方，5秒】
机位：zone03入口（z=-4），中高，面向北方黑暗
画面：黑暗中什么都看不见
然后 — 画面右侧极暗的阴影里，有一个轮廓
那是Vex，她已经在那里了，靠着墙

玩家此刻在画面外（画面南侧）
我们先看见Vex，玩家还不知道

镜头停3秒。Vex一动不动，看着画面外（南方）。
意图：观众先于玩家发现了她——这制造了一种无声的紧张。
```

```
【切 — 回到跟随镜头，玩家背后】
玩家走进区域，画面恢复正常的背后跟随视角
玩家不知道前方有人，镜头也"回到无知状态"
```

```
【Vex突然开口前 — 1秒暂停】
玩家走到z=-5.5时，画面里Vex的轮廓开始从阴影里清晰起来
这1秒里没有台词，没有音效，只是她的轮廓变得可见

然后她说话。
```

---

## "不管他们告诉你下面有什么——都是谎言。"

```
【不切镜 — 背后跟随，玩家停下】
玩家停下的一帧，镜头也停下
画面里：玩家背影（近）/ Vex（远，半在阴影里）

Vex说这句话时，我们始终看着她的背面或侧面
她没有正对镜头，这不是表演给镜头看的台词，是说给玩家听的

这整句话只用一个镜头说完，不切
```

---

## 对峙构图：全游戏唯一一次

```
【对峙镜头 — 玩家与Vex之间，2秒】
机位：二人正中，与二者等距，地面高度（约1m）
画面：左侧玩家背影，右侧Vex正面（但仍在半阴影里）
背景：黑暗走廊

这是全游戏唯一一次"对峙构图"——两个角色都在画面里，面对面
前两场遭遇刻意回避了这种构图
Vex值得这一个镜头，因为她是唯一平等地站在玩家面前的人（不是挡路，不是试探）

镜头停在这里，2秒，等她的下一句话
```

---

## "冕灵。壮者。我们来了。"

```
【特写 — Vex的嘴，说完最后三个字】
只是嘴，阴影里，说"我们来了"
然后切黑0.1秒（战斗开始）

意图：这三个字不需要任何视觉配合，只需要她的声音
特写是为了让这三个字感觉是从很近的地方说出来的——贴着耳朵
```

---

## 战斗结束：她站着，什么都没发生

```
【广角 — 全景，但不俯视，这次平视】
机位：与角色等高，中远距离
画面：冕灵光芒暗淡，壮者坐回地面，Vex站着

注意：Vex没有倒下。
她站着。之前的两个角色都倒地了，她没有。
镜头用平视而不是俯视来强调这一点——她没有被"压下去"。
```

```
【长时间沉默 — 维持这个广角，8秒】
Vex什么都没说。镜头不动。
8秒是很长的时间。
这8秒是她在想某件事。观众不知道是什么。

不要用音乐填满这8秒。
```

---

## "你的铁皮兽背上的印记。"

```
【切 — Vex的视线，向下看铁皮兽】
机位跟随她的视线，俯视铁皮兽背甲
画面里的印记和阿卡娜笔记本里的图案被观众记得
镜头在印记上停0.5秒

【切 — 回到广角】
她侧身，让出通道
画面里出现了一直被她挡住的走廊——和远处的蓝光
这是蓝光第一次清晰地出现在画面里（之前一直被她的身体遮挡）

意图：她让开了路，才让玩家看见了终点。
```

---

## 她消失

```
【玩家开始向北走 — 跟随镜头恢复】
镜头回到玩家背后跟随

玩家经过Vex站过的位置，镜头顺带扫过那个阴影
阴影里空了。

不做任何特效，不做消失动画。
她就是不在了。
```

---

## 情绪节点总结

| 动作/台词 | 镜头 | 意图 |
|-----------|------|------|
| 玩家还未到达 | 固定镜头，先看见Vex | 观众先知道，制造无声紧张 |
| "都是谎言" | 不切，玩家停下 | 一个镜头说完一句话 |
| 对峙 | 唯一对峙构图，平等 | 她不是障碍，她是对等的存在 |
| "我们来了" | 特写嘴 | 声音比画面更近 |
| 战斗后 | 平视广角，她站着 | 她没有被打败 |
| 8秒沉默 | 镜头不动 | 时间属于她 |
| 让出通道 | 蓝光第一次出现 | 她挡着终点，她让开了 |
| 消失 | 镜头扫过空阴影 | 她就是不在了 |
