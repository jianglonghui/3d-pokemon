# HATeMON 3D

一个用 **Godot 4** 制作的 3D 缚灵冒险原型。

玩家扮演一名沉默的冒险者，带着两头缚灵踏入铁心地窟。地窟以区域照明营造幽深感，遭遇三名各怀心事的对手，击败全部后方可深入下一层。

## 运行

1. 安装 [Godot 4.6+](https://godotengine.org/)
2. 打开项目：`File → Open Project` → 选择本目录
3. 运行主场景（`F5`）

> macOS 用 Homebrew 安装：`brew install --cask godot`

## 操作

| 按键 | 动作 |
|------|------|
| `WASD` | 移动 |
| `Space` | 与 NPC 互动 / 确认 |
| `Esc` | 暂停 |

## 项目结构

```
world/       地牢场景、玩家、NPC、序列过场
battle/      战斗逻辑与视觉编排
pokemon/     各缚灵程序化视觉（Shader + 粒子）
trainer/     训练师数据（.tres）
story/       角色档案与剧本
```

## 缚灵

| 缚灵 | 归属 | 特征 |
|------|------|------|
| 铁皮兽 | 玩家 | 金属甲壳，装甲环，钢蓝发光 |
| 刺背 | 玩家 / 加雷斯 | 骨刺放射，绿色有机涌动 |
| 幻灵 | 阿卡娜 | 半透明等离子，多层叠加 |
| 冕灵 | Vex | 金冠圣光，向上粒子柱 |
| 壮者 | Vex | 巨型暗红，熔岩裂缝脉冲 |

所有缚灵视觉均为程序化生成，无需外部模型资源。
